# 청자골 아학 어휘 앱 (PWA)

초등 교과서 어휘력 교재 앱과 학급용 어휘카드를 **한 번 홈 화면에 추가하면 인터넷 없이도** 아이폰·아이패드·안드로이드에서 쓸 수 있게 만든 저장소입니다.
(HTML 파일을 직접 전송하면 아이폰에서는 QuickLook 미리보기로 열려 JavaScript가 실행되지 않습니다. 그래서 HTTPS에 올린 PWA로 바꿨습니다.)

|---|---|---|
| 처음 화면 | https://phdkim0244-droid.github.io/ahak-vocab/ | 안내 |
| 청자골 아학 어휘력 (교재 앱) | https://phdkim0244-droid.github.io/ahak-vocab/vocab/ | 학생·교사 |
| 어휘카드 (학급용) | https://phdkim0244-droid.github.io/ahak-vocab/card/ + 학급 링크 | 학생 |
| 어휘카드 배포도구 | https://phdkim0244-droid.github.io/ahak-vocab/admin/ | 교사 |

## 학생 안내문 (한 장)

> **📚 청자골 아학 어휘카드 설치하기 — 딱 한 번만 하면 돼요**
>
> 1. 선생님이 알려 준 **링크를 열거나 QR을 카메라로 찍어요.**
>    아이폰·아이패드는 꼭 **Safari**로, 안드로이드는 **Chrome**으로 열어요.
> 2. **홈 화면에 추가**해요.
>    - 아이폰·아이패드: 화면 아래 **공유 버튼**(네모에 화살표 ⬆) → **홈 화면에 추가** → **추가**
>    - 안드로이드: 오른쪽 위 **⋮** → **홈 화면에 추가**(또는 **앱 설치**)
> 3. 홈 화면에 생긴 **어휘카드** 아이콘으로 열어요. 이제 **인터넷이 없어도** 돼요.
>
> ※ 꼭 홈 화면 아이콘으로 열어야 학습 기록이 이어져요. (학습 기록은 각자 기기에만 저장돼요.)
> ※ 새 학기에는 선생님이 새 링크를 줘요. 표지 왼쪽 위 **학급 설정 바꾸기**로 직접 바꿀 수도 있어요.

교재 앱(어휘력)은 링크 없이 `vocab/` 주소를 열고 똑같이 홈 화면에 추가하면 됩니다.

## 교사용 흐름

1. `admin/`(배포도구)에서 학교·학급·학년·학기·과목(출판사)을 고릅니다.
2. **학급 링크 · QR 만들기** → 링크 복사 / QR 이미지 저장 / 안내문 복사 / 안내문 인쇄(A4 한 장).
3. 알림장·학급 메신저에 링크를 붙여 넣거나, QR을 TV·인쇄물로 보여 줍니다.
4. **미리보기**는 학습 기록이 저장되지 않는 모드(`&pv=1`)로 학생용 화면을 엽니다.

학급 링크 형식: `card/#g=5&s=1&sc=학교&c=반&sub=국어:국정,수학:출판사,…` (한글은 퍼센트 인코딩).
학생용 앱은 처음 열 때 해시의 설정을 `localStorage`에 저장하고, 주소에도 항상 해시를 유지합니다. 그래서 홈 화면에 추가한 아이콘(아이폰은 Safari와 저장소가 분리됨)으로 열어도 같은 학급 설정으로 시작합니다. 링크 없이 열리면 학급 설정 화면이 나옵니다.

## 구조

```
index.html            처음 화면(안내)
vocab/                교재 앱 PWA  (index.html, data.js, manifest, sw.js, 아이콘)
card/                 학급용 어휘카드 PWA (index.html, cover.jpg, manifest, sw.js, 아이콘)
admin/                교사용 배포도구 (PWA 아님, QR 생성에 cdnjs qrcode-generator 1개 사용)
shared/data.js        교과서 어휘 자료 5,325개 (card·admin 공용)
shared/fonts/         한자용 Noto Serif KR 서브셋 woff2 (1,196자, 오프라인용)
src/                  편집용 부품(css·js·html) → tools/build.py 가 위 index.html 들을 생성
_src/                 원본 HTML 3개 (참고용, 손대지 않음)
docs/screenshots/     오프라인 동작 검증 스크린샷
```

## 수정·배포 방법

1. `src/` 안의 파일을 고친 뒤 **반드시** `python3 tools/build.py` 를 실행합니다. (서비스 워커 버전이 내용 해시로 자동 갱신되어, 학생 기기에서 다음 실행 때 새 버전으로 자동 교체됩니다.)
2. `git add -A && git commit -m "..." && git push` → GitHub Pages가 1~2분 안에 반영합니다.
3. 어휘 자료를 바꾸려면 `shared/data.js`(카드·배포도구) 또는 `vocab/data.js`(교재 앱)를 고치고 1번을 다시 실행합니다.

## 동작 원리(요약)

- 서비스 워커가 설치 시 전체 자산을 프리캐시(cache-first)하고, 새 `sw.js`가 올라오면 자동으로 교체·새로고침합니다.
- 서비스 워커는 HTTPS(또는 localhost)에서만 등록되므로 교실 LAN의 http 서버로는 설치가 안 됩니다.
- Google Fonts 링크를 없애고 본문은 시스템 글꼴, 한자는 동봉한 woff2를 씁니다.
