홈 화면에 추가하기 (한 번만)

  1. 아이폰·아이패드: Safari로 열기 → 아래쪽 공유 버튼(네모에 화살표) → 홈 화면에 추가 → 추가
  2. 안드로이드: Chrome으로 열기 → 오른쪽 위 ⋮ → 홈 화면에 추가(또는 앱 설치)
  3. 그다음부터는 홈 화면 아이콘으로 열면 인터넷 없이도 돼요. 학습 기록은 각자 기기에만 저장돼요.
